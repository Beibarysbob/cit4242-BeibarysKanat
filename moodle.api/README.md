    _Virtual Gamepad Emulator_
I intend to build a virtual gamepad emulator 
that allows users to control games using a keyboard 
while the game receives the input as if it came from 
a game controller.

Because different old games are builded for different 
types of gamepads, users will be able to create different 
controller profiles and map keyboard keys to gamepad buttons, 
directional controls and analog stick actions.

I also want to experiment with converting digital keyboard 
input into smoother analog input, which could make 
keyboard controls more suitable for racing and sports games.
